# Context index

Last verified: 2026-10-14

Research files for Black Turtle Salon, split by topic. Each file has its own sources list. Facts are copied from the sources, not paraphrased. Verified facts also live in `content/` (`salon-facts.md`, `services.json`, `reviews.md`); those files are the originals and are not edited here.

## Files
- `salon-identity.md`: name, former name, signage, Google category, accessibility, rating, Instagram stats.
- `location-contact.md`: address, Plus Code, coordinates, phone, email, social links, booking URLs.
- `opening-hours.md`: hours from Salonic and Google Maps, with the open Saturday conflict.
- `services-pricing.md`: all 10 services × 3 stylist levels, with prices, durations, and full Hungarian descriptions.
- `team.md`: barbers, levels (HU and EN), photo URLs, missing bios.
- `booking-policy.md`: Salonic booking flow and start URL, 24 h cancellation, indicative prices, languages.
- `reviews.md`: verbatim Google review quotes, display rules, and the exclusion note.
- `design-reference-saint-urbain.md`: structural design reference only (type, spacing, grid, motion). No content or colours.
- `not-found.md`: lookups that found nothing, and lookups that failed or were blocked.
- `interior-analysis.md`: being written by another agent. Not present yet.
- `reference-train-journey.md`: being written by another agent. Present now; not reviewed by this file set.
