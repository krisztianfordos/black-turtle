# Black Turtle Salon — brand & website

Brand system and website project for Black Turtle Salon, a men's hairdressing & barbering salon at 1056 Budapest, Szerb utca 8. The project is currently in the concept / design-system phase. Design work lives in Paper: https://app.paper.design/file/01M4WS0X30AFDSN4WHVWCG52S1

## Structure

- `CLAUDE.md` / `AGENTS.md` — project guide for AI agents (identical)
- `content/` — verified salon facts, services, reviews
- `assets/` — logo cut-outs, photos, textures; `assets/src/` holds the originals
